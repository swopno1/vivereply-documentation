# Blog Tags — Staff Training Module

**Page:** `/admin/blog/tags` — finer-grained labels.
**Audience:** editors, managers.
**Time to complete:** about 10 minutes.
**Prerequisite:** the [Blog](..) module.

## Learning objectives

After this module you can use tags to connect posts without creating
category clutter.

## 1. What tags are

Where a category is the shelf, **tags are the threads** tying posts
together across shelves: a post in *Destinations* tagged *hiking* sits
beside a post in *Guides* tagged *hiking*. Guests clicking a tag discover
related posts they'd never have browsed to. Tags carry the same fields as
categories: name, Bengali name, slug, description, display order, active
flag, post count.

**Permission:** managing taxonomy needs the edit permission.

## 2. Tagging well

- **Reuse, don't invent.** Check the existing tags before creating a new
  one — *beach*, *beaches*, and *sea-beach* as three tags is a discovery
  failure. The tag list should grow slowly.
- **A few per post.** Three to six good tags beat fifteen vague ones.
- **Think like a guest searching:** *family-trip*, *budget*, *monsoon*,
  *seafood* — the words travelers actually use.

## 3. Troubleshooting

| Symptom | Check first |
|---|---|
| Near-duplicate tags | Merge by deactivating the weaker one and retagging its posts. |
| Tag with one post | Probably too specific — consider folding it into a broader tag. |
