# Vivereply Chat — Documentation

**What:** the AI chatbot for business websites.
**Status:** **in development** — this page describes the direction, not a
live product.

## 1. What it will be

Vivereply Chat is the standalone AI chatbot product: a business puts it
on their website, and it answers visitors from the business's own content
— pages, docs, FAQs — using retrieval-augmented generation (RAG). Where
the [Concierge](../concierge/) is a front-desk agent wired into live
booking data, Chat is the generalist: **any business, any website,
answering from that business's knowledge.**

## 2. How it differs from the Concierge

| | Concierge | Chat |
|---|---|---|
| **Scope** | One domain: the resort front desk | Any business website |
| **Data** | Live Suite data via tools (availability, quotes, drafts) | The business's content via RAG |
| **Actions** | Books drafts, verifies bookings, hands off | Answers, guides, captures leads |
| **Framing** | Front-desk agent, never an MCP | Website assistant |

They share the family traits: grounded answers (tools or retrieval, never
raw hallucination), handoff to a human when stuck, and the business's
voice — not a generic bot.

## 3. Current status

The full Chat is a **parallel track** alongside the Concierge — not live
yet. These docs will grow with it: embedding, knowledge sources, lead
capture, and the dashboard. Until then, this page is the placeholder that
says so honestly.

*If you're evaluating Vivereply today: the Suite is live, the Concierge
is the AI story in production, and Chat is what's next.*
