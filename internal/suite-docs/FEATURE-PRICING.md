# Feature Pricing & Monetization Guide

This document outlines the agency pricing structure, licensing models, and suggested add-on pricing for selling custom resort & hotel web platforms using this scaffold.

---

## 1. Core Scaffold Base Package

### Baseline Website Setup: $2,000 – $3,500 (One-Time)
The core scaffold delivers a high-performance, mobile-first resort website built for maximum conversion in Bangladesh.

**Included Core Features:**
- Custom visual identity integration (Logo, colors, typography, brand assets)
- Full bilingual support (English & Bangla script)
- Mobile-optimized multi-step Booking Engine (`/book/[roomId]`)
- Integrated bKash Tokenized Checkout V2 (included in base package; Nagad & SSLCommerz available as modular add-ons)
- Property showcase (Hero search, room cards, amenities, photo gallery, blog)
- Admin Portal (`/admin`) for inventory management, lead tracking, and report downloads
- High-speed BDIX VPS setup (<15ms latency in Bangladesh) with SSL certificate

## 2. Premium Add-On Monetization Modules

Agency sales reps can offer modular feature add-ons during sales conversations or post-launch upsells.

| Feature Module | Key Deliverables & Client Benefit | One-Time Setup Fee | Suggested Monthly Maintenance / API Pass-through |
| :--- | :--- | :--- | :--- |
| **Interactive Map Module** | Custom interactive map view with resort location, nearby landmarks, and turn-by-turn directions. | **$300 – $500** | Included in standard retainer |
| **Google Business Profile (GMB) Reviews** | Live cached Google Reviews feed with star ratings, cron auto-refresh, and structured schema markup. | **$250 – $400** | Included in standard retainer |
| **Local Area & Destination Guide** | Rich interactive guide covering nearby attractions, dining, day trips, and custom travel itineraries. | **$400 – $600** | $50 / month (content updates) |
| **AI Concierge Chatbot (RAG)** | 24/7 AI travel concierge trained on property policies, menus, and local knowledge to convert guest inquiries. | **$800 – $1,200** | $50 – $100 / month (OpenAI API usage + vector index maintenance) |

## 4. Recurring Retainer Packages

Maintain recurring revenue from resort clients by bundling hosting, API management, and content updates:

- **Essential Retainer ($150 / month)**:
  - BDIX VPS hosting management & SSL renewals
  - Automated daily SQLite backups to Cloudflare R2
  - Core uptime & security patching
- **Growth Retainer ($300 / month)**:
  - Everything in Essential Retainer
  - OpenAI & Google Places API quota management
  - Up to 2 hours/month of content and promotional package updates
  - Quarterly SEO audit and sitemap updates
